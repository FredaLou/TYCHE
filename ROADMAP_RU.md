# 🗺️ Дорожная карта TYCHE

Этот документ описывает текущий статус разработки, реализованную архитектуру и планы на будущее.

## ✅ Реализовано (v1.0 - Базовое ядро)
*Фундамент стабилен и полностью функционален.*

| Функция | Детали реализации |
| :--- | :--- |
| **Локальный LLM-сервер** | `llama.cpp` с поддержкой GPU и speculative decoding (`start_server.bat`) |
| **Чат со стримингом** | Управление контекстом и потоковая передача (`core/chat.py`, `orchestrator.py`) |
| **Модульный оркестратор** | Разделение обработчиков и централизованный конфиг (`core/orchestrator.py`, `config.yaml`) |
| **Память фактов** | JSON-хранилище с валидацией на быстрой модели (`memory.json`, `memory_writer.py`, `fact_validator.py`) |
| **Векторная RAM** | ChromaDB с эпизодами-суммари (`memory/vector_memory.py`) |
| **Гибридный поиск** | Семантика + стоп-слова + учет давности, слои hot/warm/cold (`vector_memory.py`) |
| **Динамическое состояние** | Скрытые параметры (`energy`, `dryness`, `detachment`, `affection`) (`utils/state_manager.py`) |
| **Суточные ритмы** | Фазы, зависящие от времени и загружаемые из конфига (`state_manager.py`) |
| **Системный промпт** | Модульный: `persona.txt` + `rules.txt` (~700 символов) (`utils/system_prompt.py`) |
| **Суммаризация** | Автоматическая генерация эпизодов каждые N сообщений (`orchestrator.py`, `utils/summarizer.py`) |

## 💡 Запланировано (v2.0+)
*Долгосрочные планы по созданию автономного поведения.*

- [ ] **Автономные импульсы (Тикер)**: 
  - Фоновый скрипт, проверяющий `[DATA]`, параметры состояния и время молчания пользователя.
  - Использование Шума Перлина для запуска спонтанной активности.
  - Правило токена `[SILENCE]` для предотвращения спама.
- [ ] **Динамическая инъекция [DATA]**:
  - Универсальный формат для внешних источников (погода, состояние ПК, цены).
  - Роутер решает, какую функцию вызвать, и внедряет результат прямо в промпт.
  - Включает логику "спорадического вранья" и обработку `NOT_FOUND` для погружения в персонажа.
- [ ] **Классификация вопросов**: Использование быстрой модели для тегирования ввода пользователя как `[МНЕНИЕ]` или `[ФАКТ]`.

## ⚠️ Известные проблемы
*Баги и ограничения, над которыми идет работа.*

- **Галлюцинации памяти**: Модель иногда выдумывает детали при попытке вспомнить контекст.
- **Мусор в JSON**: Дублирование фактов будет происходить до завершения миграции на SQLite.
- **Дрейф персоны**: Модель иногда выходит из роли и возвращается к стандартному режиму «полезного ассистента».
